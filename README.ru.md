# WhisperWriter — диктовка для Windows без интернета

> **Альфа-версия.** Возможны ошибки, настройки и поведение могут меняться от
> выпуска к выпуску. [English — README.md](README.md).

Нажали клавишу, сказали, замолчали — текст печатается в окно, где стоит курсор.
Без регистрации. При первом запуске скачивается модель распознавания, дальше
интернет не нужен, и звук никуда с компьютера не уходит.

Программа бесплатная, даётся как есть, на ваш риск. Прочитайте
[DISCLAIMER.md](DISCLAIMER.md#русский), прежде чем на неё полагаться.

Это доработка программы [savbell/whisper-writer](https://github.com/savbell/whisper-writer)
под ежедневную работу в Windows. Подробно о том, что изменено и почему, — в
[README.md](README.md) на английском.

## Установка

### Готовая сборка — ничего не устанавливать

1. Откройте [страницу выпусков](https://github.com/schwarzmeewolf/offline-dictation-windows/releases)
   и скачайте `WhisperWriter-<версия>-windows-x64.zip` из самого верхнего выпуска.
2. Распакуйте архив в отдельную папку, например `C:\WhisperWriter`. Папку не
   разбирайте: `WhisperWriter.exe` нужна папка `_internal` рядом.
3. Запустите `WhisperWriter.exe`. Windows может показать «Система Windows
   защитила ваш компьютер» — программа не подписана платным сертификатом,
   больше это ничего не значит. Нажмите **Подробнее**, потом **Выполнить в
   любом случае**.
4. Выберите язык, нажмите клавишу, которой будете начинать диктовку, и
   нажмите **Сохранить** в окне настроек — все поля уже заполнены.
5. Программа один раз скачает модель (около 460 МБ). Когда в трее (у часов)
   появится значок — можно диктовать.

Эта сборка работает только на процессоре. Чтобы диктовка шла на видеокарте
NVIDIA — быстрее и точнее, — ставьте из исходников, как ниже.

### Из исходников, без командной строки

1. Установите **Python 3.11** — «Windows installer (64-bit)» со страницы
   <https://www.python.org/downloads/release/python-3119/>. Галочки оставьте как
   есть, особенно **py launcher**. Более новый Python не подойдёт.
2. На этой странице нажмите зелёную кнопку **Code** → **Download ZIP**.
   Распакуйте в папку с коротким путём, например `C:\WhisperWriter` — не на
   Рабочий стол и не в Загрузки: у Windows ограничение на длину пути.
3. Дважды щёлкните `install.bat`. Он поставит компоненты (около 500 МБ),
   проверит их, создаст ярлык в меню «Пуск». Если есть видеокарта NVIDIA,
   предложит поддержку видеокарты. Все сообщения — на русском и английском.
4. Первый запуск — как в шаге 4 выше.

## Как пользоваться

- Нажмите клавишу диктовки, говорите, замолчите на две секунды — текст
  напечатается туда, где курсор.
- Язык диктовки можно сменить на время в меню значка в трее.
- Настройки — правой кнопкой по значку → **Открыть настройки**. У каждого поля
  есть кнопка «?» с объяснением.
- Если программа не смогла вернуться в окно, куда вы диктовали, она не печатает
  текст куда попало, а кладёт его в буфер обмена и пишет об этом. Вставьте
  его сочетанием Ctrl+V.
- Если клавишу диктовки уже заняла другая программа (например, Ctrl+Alt+Space
  занимает приложение Claude), программа предупредит. Выберите другую клавишу.

## Обновление

Настройки хранятся в папке `%APPDATA%\WhisperWriter`, а не в папке программы,
поэтому обновление их не трогает.

- **Готовая сборка:** закройте программу (значок в трее → **Выход**), удалите
  старую папку, распакуйте на её место новый архив, запустите `WhisperWriter.exe`.
- **Исходники из ZIP:** закройте программу, распакуйте новый ZIP поверх старой
  папки, снова запустите `install.bat`.

Чтобы узнавать о новых версиях: вверху страницы на GitHub нажмите **Watch →
Custom → Releases** (нужен бесплатный вход в GitHub).

## Если что-то не работает

1. Щёлкните правой кнопкой по значку WhisperWriter в трее → **Сведения для
   поддержки**. Программа запишет файл `support-info.txt` и откроет папку с
   ним. В файле версия, настройки без ключей, микрофон и последние строки
   журнала — продиктованного текста и паролей там нет.
2. Откройте [форму обращения](https://github.com/schwarzmeewolf/offline-dictation-windows/issues/new/choose),
   ответьте на три вопроса — что делали, что произошло, чего ждали — и
   перетащите туда файл.
